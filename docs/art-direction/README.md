Ortak kurallar

- Işık: tek sert kaynaklar (sokak lambası, fener, ateş), hacimsel sis, yağmur ıslaklığı.
- HUD: sol altta ince can (yeşil) ve dayanıklılık (beyaz) çubuğu, sağ altta silah ikonu; minimal, köşeli.
- Mobilde performans önce: düşük poligon + iyi ışık/sis/post-process, pahalı efektler kalite ayarına bağlı.
