# RESET NIGHT

Mobil hayatta kalma oyunu. İlk oynanabilir sürüm: tek oyunculu, çevrimdışı gece savunması.

## Kontroller
- Sol sanal joystick: hareket
- VUR: yakın dövüş
- ATEŞ: en yakın düşmana ateş
- İLK YARDIM: sağlık yenile
- DOLDUR: şarjör doldur
- Klavye: WASD, Space, J, H, R

## APK
GitHub Actions > RESET NIGHT Android APK iş akışı > başarılı çalışmanın `RESET-NIGHT` artifact dosyası.

Oyun adı ve resmî logo korunur. Rekor cihazda saklanır.
